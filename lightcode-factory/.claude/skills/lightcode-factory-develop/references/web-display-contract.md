# 统一页面契约

目标：每个 Workflow 独立实现，但所有 run 使用同一套看板、运行详情和轨迹。业务插件提供数据，不拥有页面。

## 1. 页面与数据的稳定映射

| Workflow 提供 | 统一页面使用 |
| --- | --- |
| metadata、parameters | 新建任务中的 Workflow 选择和参数表单 |
| run status | 六状态看板、状态标签和动作可用性 |
| nodes 顺序和状态 | 整体进度与横向节点轨道 |
| 当前选中节点的 output/error | 节点输出工作区 |
| run 基本字段 | 运行信息 |
| Runtime 生命周期事件 | 事件时间线 |
| node observations | 轨迹页的时间概览、账本和详情检查器 |

运行详情回答“执行到哪里、每个节点产出了什么”；轨迹回答“模型、工具和进程内部如何执行”。两者不得重复承担同一职责。

## 2. 节点轨道和输出联动

- 节点轨道同时承担进度展示和输出选择。
- 点击任意节点后，标题、状态和输出必须切换到对应节点。
- 运行中默认选择当前节点；终态 run 默认选择最近一个有 output 或 error 的节点；没有结果时可选择首节点。
- Workflow 应为每个节点返回能够独立理解的结果，不假设页面永远只看最后节点。
- 节点多或窗口较窄时由 Web 根据真实内容溢出提供横向浏览；Workflow 不关心固定节点数量、像素或断点。

若修改共享 Web，必须保持“能容纳时平铺，真实溢出时才横向浏览”，且不能让提示元素本身制造溢出。普通 Workflow 任务不得修改这套逻辑。

## 3. Output 设计原则

通用保证是：未知 JSON-safe output 可以格式化展示。设计 Workflow 时优先保证通用回退可读，不要依赖偶然的 UI 猜测。

某些当前 renderer 可能识别问候、代码、进程结果等语义字段。Agent 使用前必须从当前 `WorkflowRunOverview` 或等价源码和测试确认：

- 识别哪些字段；
- 字段类型和组合条件；
- 是否会关联前序节点输出；
- 空值、错误和未知结构如何回退。

只有稳定、跨 Workflow 可复用的输出语义才允许扩展 renderer。禁止：

- `if (workflowId === ...)`；
- 按包名、demo 名称、节点 id 或节点中文名称判断；
- 为一个业务复制整套运行页；
- 没有通用回退；
- 把 observation 原文塞入运行详情。

确需新 renderer 时，先把它设计为公开的语义契约，并为已知形状、未知形状和节点切换补测试。这属于 Web 变更。

## 4. Observation 与轨迹

Workflow 使用当前约定的 observation kind 表达：

- 模型输入、安全的推理摘要和响应；
- 工具调用及结果；
- 进程启动及结果；
- 节点上下文日志；
- 领域事实。

轨迹负责按节点、类别、时间、callId 和 sessionId 组织这些信息。运行详情只展示 output/error 和 Runtime 生命周期事件，不显示工具调用明细。

设计 observation 时先检查当前轨迹映射。未识别 kind 必须仍能安全落入通用类别；不要为了换颜色或图标修改业务语义。

## 5. 统一布局不由 Workflow 控制

Web 的信息层级应保持：

1. 页面头部和“运行详情 / 轨迹”页签；
2. 整体进度与节点轨道；
3. 节点输出与运行信息；
4. 独立纵向事件时间线；
5. 轨迹工具栏、时间概览、记录列表和详情检查器。

具体列宽、节点基准宽度、颜色、动效、断点和 viewport 是当前 Web 实现细节，Workflow 规范不固定它们。Agent 只需保证：

- 节点名称简洁且可区分；
- output 在单节点工作区内可读；
- 大内容有滚动或 artifact 策略；
- 页面在完整桌面浏览器和较窄窗口中均能使用；
- 事件在宽屏仍纵向排列。

## 6. 页面适配自检

实现前确认：

- 每个节点点击后应该看到的 output 已写入设计；
- output 使用通用 JSON 或当前已验证的语义 renderer；
- observation 没有被当作最终结果；
- 没有要求 Web 认识 Workflow id；
- 节点数量增加时不要求业务代码处理滚动；
- 错误节点和无输出节点仍有合理页面状态；
- review、cancelled、failed 等状态使用底座统一动作和视觉语义。

若这些稳定语义、renderer 契约、轨迹分类或页面职责发生变化，必须在同一变更中刷新 `docs/architecture.md`、本文件和 Web 测试；不能只修改组件实现。
